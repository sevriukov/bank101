# Описание таблиц

Имя файла — `data/<папка>/<имя>.csv.zst`; в скобках — имя таблицы в базе PostgreSQL (схема.таблица).
Общие обозначения: `regn` — регистрационный номер банка (номер лицензии Банка России); `dat` — отчётная дата
(первое число месяца; остатки на начало этого дня, обороты — за предшествующий месяц); `konto` — пятизначный номер счёта
второго порядка; `ap` — сторона счёта: 1 — актив, 2 — пассив; `ch_id` — номер узла дерева. Суммы — в тысячах рублей.

## Столбцы формы 101

| Столбец | Содержание |
|---|---|
| `vr`, `vv`, `vi` | входящий остаток: в рублях, в иностранной валюте и драгоценных металлах (в рублёвом эквиваленте), итого |
| `ora`, `ova`, `oia` | оборот по дебету: рубли, валюта, итого |
| `orp`, `ovp`, `oip` | оборот по кредиту: рубли, валюта, итого |
| `ir`, `iv`, `ii` | исходящий остаток: рубли, валюта, итого |

она не вошла (см. README, «Воспроизводимость»). Файл `0808_all.mdb` — копия июльского файла 2008 г.

## 8_vector — векторный слой

| Файл (таблица) | Строк | Содержание |
|---|---|---|
| `matryoshka_cells` (m.dig_cell) | 14,8 млн | оригинал оцифровки в обычном виде: банк, дата, лист дерева, срочность → остаток в рублях и валюте, оборот по дебету и кредиту в рублях и валюте, тыс. руб. |
| `matryoshka_axes` (m.dig_axis) | 161 | ячейки «лист × срочность» |
| `matryoshka_coords` (m.dig_coord) | 968 | смысл каждой координаты вектора |
| `matryoshka_state_vectors` (m.dig_state) | 296 250 | точка «банк на дату»: вектор из 968 чисел (966 координат в долях валюты баланса, логарифм валюты баланса, время в годах от 01.01.1998) и признаки `turn_known`, `split_known`, `after_revoke` |
| `matryoshka_scale` (m.dig_scale) | 966 | параметры приведения метрик: среднее, отклонение, обрезка, вес |

Столбец `after_revoke` в векторах — отчётность после отзыва лицензии; дата отзыва взята из справочника судеб банков,
который в эту часть публикации не входит. Лакуна — отсутствие сведений, а не ноль: внутри вектора пропуск записать нельзя,
поэтому там стоит ноль и действуют признаки `turn_known` и `split_known`. Векторы с приведёнными метриками (логарифм
оборотов, стандартизация, обрезка, веса) в пакет не входят — они строятся материализованным представлением по
`code/105_matview.sql` из параметров `matryoshka_scale`; подробности — `docs/ОЦИФРОВКА_описание.md`.
